# 实现说明：现代苹果风格的 Cover Flow 重设计

这份说明给负责实现的人（或 AI）。目标是把扩展界面改成设计稿里的样子：保留 Cover Flow 的 3D 翻页和镜面倒影，整体换成现代、扁平的苹果风格（类似 macOS 版 Apple Music、系统设置）。

## 设计稿

- 画布：https://claude.ai/artifact/11mDWBdygkz9Sp3Ec8rsxh
  - 用 Artifact 工具的 `read` 读取。每个画板是一个 `project/<名字>.dc.html` 文件，用 `path` 参数分别读取。
  - 画板里的 HTML/CSS 是**视觉参考**，不是可以直接拷贝的代码。颜色、尺寸、文案以它为准，结构按本仓库现有的写法来做。

## 原则

1. **视觉全面替换，架构不动。** 继续按 Domain → Application → Infrastructure → UI 分层，继续用原生 TypeScript，不引入框架。
2. **去掉现有的 Liquid Glass 视觉**：`effects/liquid-*.ts`、`hdr-glass.ts`、`liquid-glass.css`、`liquid-controls.css`，以及粉色系 tokens。改成扁平的中性灰界面，颜色只来自封面。删除前先确认没有别的模块依赖它们。e2e 里的 `glass-surfaces.spec.ts`、`motion-and-glass.spec.ts` 也要相应改写或删除。
3. **运动模型保留。** `motion.ts` 的临界阻尼弹簧，以及滚轮、触控板、拖动、键盘这些控制器都不变，只换几何映射和视觉。
4. **隐私、本地优先、无障碍、多语言这些现有承诺一条都不能少。**

## 舞台几何（替换 `getCoverTransform`）

`offset` 表示某张封面距离中心几个位置，可以是小数。这套参数是给 240px 的封面定的；实际尺寸不同时按比例缩放（比如用 `--cover-size` 换算）。

```
a = |offset|，s = sign(offset)，t = min(a, 1)
x       = a < 1 ? offset × 178 : s × (178 + (a − 1) × 60)    // px
z       = 40 − 160 × t                                      // 中心 +40，两侧 −120
rotateY = s × angle × t                                     // angle 默认 70°，设置里可调 45–80°
opacity = a ≤ 7 ? 1 : 0                                     // 7 到 8 之间做平滑淡出
```

- 右侧封面（offset > 0）是 `rotateY(+angle)`：远离中心的外边缘往里退，靠近中心的内边缘更近、更高。写完先目视确认一下方向对不对。
- 透视参数：`perspective: 1100px`，`perspective-origin: 50% 55%`。
- 层叠顺序：不要用 `preserve-3d`，按离中心远近设 `z-index`（`100 − a`）。
- 封面：
  - 圆角 = 边长 × 4.2%（240px 时是 10px）。
  - 加封面投影。
  - 侧面封面盖一层渐变暗影：浅色主题从 2% 到 16%，深色主题从 10% 到 50%，靠外的一侧更暗。鼠标悬停时暗影减半。
- 倒影：
  - 用 `-webkit-box-reflect: below 2px linear-gradient(transparent 62%, rgb(255 255 255 / 30%))`；浅色主题用 `transparent 64%, … / 20%`。
  - 设置里可以关掉。
  - 这是 Chrome 专有属性，扩展只跑在 Chrome 上，可以放心用。
- 鼠标悬停中心封面时，底部浮出一个“打开 ↗”胶囊：高 28，`rgb(0 0 0 / 55%)` 底加 12px 背景模糊，白字 12/600。点击后胶囊文字变成“正在打开…”，同时封面在 100ms 内缩到 0.97 再回弹。
- 滚动条：
  - 用原生 `input[type=range]`：轨道 4px、圆角 2，滑块高 4px，宽度 = 可见数 ÷ 总数 × 轨道宽，最小 24px。
  - 鼠标悬停时滑块加粗到 6px。
  - 宽度取 `min(480px, 56%)`。
  - 拖动滑块会驱动 `targetPosition`。
- 保持现有的虚拟化：只渲染 `selectedIndex ± 7` 的封面。

## 动效

- 继续用现有的弹簧，调 `frequency`，让单次翻页手感接近 620ms 的 `cubic-bezier(.22,.8,.24,1)`：起步快、落位轻、不过冲。
- 按住方向键时每 90ms 前进一张。拖动时 60px 算一张，松手后带惯性，最后吸附到最近一张。
- 系统开启“减弱动态效果”，或设置里打开“减弱翻页动画”时：不做旋转动画，直接 150ms 交叉淡入。

## 生成封面（对应 `Cover.dc.html` 和 `resolve-cover.ts`）

网站没有 Open Graph 预览图时，生成一张专辑式封面：

- **选模板**：同一个域名永远得到同一种。模板 = 域名哈希 % 4，四种模板是 `mono` / `type` / `circle` / `bands`。
- **颜色**：底色优先用网站的 `theme-color`，没有就取 favicon 的主色；前景色按对比度在黑白里选。强调色：`circle` 模板用底色的互补色，其余模板从底色派生。
- **四种模板**（尺寸都按 240px 封面写，其他尺寸等比缩放）：
  - `mono`：标题首字（西文取前两个大写字母，例如 TS）。字号 176，名称只有两个字母时 132；字重 800，字距 −0.06em。左下角依次是一条 28×3 的强调色短线、名称 14/700、域名 10。
  - `type`：名称拆成两行，字号 50、字重 800、行高 0.94，第二行用强调色；底部放域名和一个强调色圆点。
  - `circle`：一个 196px 的强调色圆从右上角出血，名称 28/800 压在左下。
  - `bands`：下方 112px 高的区域是 5px 粗、13px 间隔的强调色细条纹，名称 30/800 放在上方。
- **加载过程**：预览图加载中先显示首字母和微光动画（shimmer），图片到了以后 200ms 交叉淡入。

## 全屏（`Fullscreen.dc.html`，新功能）

- 黑底，封面 340px，侧面偏移 252 + 84n，z 轴 +60 / −170。
- 背景：放一块 900×600、`filter: blur(140px)`、不透明度 0.42 的色块，颜色取当前封面的底色，换封面时用 `background-color` 做 0.8s 过渡。
- 控件：
  - 左上角是关闭按钮：32px 圆形，`rgb(255 255 255 / 12%)` 底加背景模糊。
  - 顶部居中显示“文件夹 · 3 / 16”。
  - 底部依次是：标题 26/700，“域名 · 文件夹”；一行三个按钮（上一个 40px 毛玻璃圆钮、白色“打开”胶囊、下一个）；最下面是滚动条。
- 入口是标题栏的全屏按钮，或按 `F` 键；按 `Esc` 或 `F` 退出。可以用 Fullscreen API，也可以只做页面内的全屏覆盖层。

## 状态（`States.dc.html`）

- 读取中：12 根短条组成的转圈指示，超过 400ms 才显示。
- 空文件夹：显示“此文件夹没有书签 / 试试其他文件夹或搜索”。
- 无搜索结果：显示“没有找到‘…’ / 试试其他关键词，或在‘全部书签’中搜索”。
- 读取失败：橙色圆形感叹号、“无法读取 Chrome 书签”和蓝色“重试”胶囊。只替换舞台区域，侧栏和列表照常可用。
- 列表里，命中搜索词的部分用 `<mark>` 高亮。
